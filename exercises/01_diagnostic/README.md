# 01 Diagnostic — Baseline & Level Check

Welcome to the diagnostic module! These 6 short exercises assess your starting baseline across:
1. Basic data structures & frequency counting (`diag1_first_unique`)
2. Pythonic idioms & sorting keys (`diag2_top_k_words`)
3. Object-oriented wrapping & dunders (`diag3_stack_class`)
4. Optimal Big-O thinking (`diag4_longest_consecutive`)
5. Writing tests that catch edge-case bugs (`diag5_clamp_tdd`)
6. Exception hierarchy & validation (`diag6_validate_user`)

## How the Mentor Uses Diagnostic Results
When you run `uv run pylings` or ask Claude Code / Codex to review:
- If you solve a challenge cleanly, the mentor logs mastery in `PROGRESSION.md`.
- Mastered topics allow you to run `uv run pylings skip <track>` so you don't waste time on concepts you already know.
- Stumbles reveal your specific target areas (e.g. edge-case testing or OOP dunders).
